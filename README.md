# DevOps Lab

A hands-on DevOps learning and experimentation
repository built using Termux on Android.

## Learning Environment

- Android
- Termux
- Git
- GitHub
- Acode

## Learning Roadmap

1. Linux Administration
2. Networking
3. Bash Scripting
4. Docker and Containerization
5. GitHub Actions and CI/CD
6. Terraform and Infrastructure as Code
7. Kubernetes and Container Orchestration

## Projects

Practical exercises, configurations, scripts,
and deployment projects will be documented here
as the lab develops.

## Purpose

To develop practical DevOps skills through
hands-on projects and documented experiments.
